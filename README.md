# 舞台演出提示编排（Stage Cue Planner）

在时间轴上编排灯光 / 音效提示：设置持续时长与“完成后触发”依赖；拖动提示时按依赖拓扑级联移动全部后继项，遇到锁定项或同轨时间冲突则整次回滚并在时间轴上标红阻塞链。支持按轨道筛选与撤销最近一次成功调整。

## 一键启动（Docker）

```bash
docker compose up --build
```

启动后访问 **http://localhost:3000**。

依赖安装与 SQLite 数据库初始化（建表 + 示例数据）均在首次启动时自动完成，数据持久化在 `cue-data` 卷中。

## 本地开发（不用 Docker）

```bash
npm install
npm start
```

同样访问 http://localhost:3000 （数据库文件写入 `./data/cues.db`）。

## 功能说明

- **提示块**：💡 灯光 / 🔊 音效，含开始时间与持续时长，🔒 表示锁定。
- **拖动级联**：拖动某提示块，其所有“完成后触发”的后继按依赖拓扑整体平移，拖动过程实时预览。
- **回滚与阻塞链**：级联路径上任一提示被锁定、越出 0 时刻，或与同轨道其他提示时间重叠时，整次操作不生效，阻塞链上的提示与依赖箭头标红抖动 3 秒，并弹出原因说明。
- **轨道筛选**：工具栏下拉框按轨道过滤显示。
- **撤销**：一键撤销最近一次成功的拖动调整（服务端保存快照，恢复前校验冲突）。
- **编辑**：点击提示块，在右侧栏修改名称 / 类型 / 轨道 / 开始 / 时长 / 锁定，并管理“完成后触发”依赖（自动拒绝循环依赖）。

## 技术栈

Node.js + Express + SQLite（better-sqlite3）+ 原生 HTML/CSS/JS（无前端框架）。

## API 概览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/state` | 全部提示、依赖与撤销状态 |
| POST | `/api/cues` | 新建提示 |
| PATCH | `/api/cues/:id` | 修改名称/类型/轨道/时长/锁定 |
| DELETE | `/api/cues/:id` | 删除提示 |
| POST | `/api/cues/:id/move` | 拖动移动（级联 + 冲突回滚 + 阻塞链） |
| POST | `/api/deps` | 新建“完成后触发”依赖（拒绝成环） |
| DELETE | `/api/deps/:id` | 删除依赖 |
| POST | `/api/undo` | 撤销最近一次成功调整 |
